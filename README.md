# Carbus · v3.0.0

CCC 광주지구의 행사 **참석 신청·차량 배정·현장 출석·수송·차량비 정산**을 함께 관리하는 웹앱입니다.
임역원이 캠퍼스 순장·순원의 정보를 대신 입력하고, 총단이 행사 전체를 운영하며,
차량순장이 담당 호차의 탑승을 확인합니다. 여러 행사의 자료를 행사별로 관리할 수 있습니다.

[서비스 열기](https://carbus-web.vercel.app) · [v3.0.0 릴리즈](https://github.com/Lumiere001/carbus-web/releases/tag/v3.0.0)

## 누가 사용하나요?

| 사용자 | 접근 방법 | 주요 업무 |
|---|---|---|
| 임역원 | Google 로그인 후 총단이 캠퍼스 권한 부여 | 본인 캠퍼스의 명단·참석·이동·납부 입력, 수송 요청, 송금 등록 |
| 총단 | 운영자 비밀번호 로그인 | 행사·사용자 권한·운행편·차량·배차·정산 관리 |
| 조회 운영자 | 운영자 비밀번호 로그인 | 전체 운영 자료 조회 |
| 차량순장 | 로그인 계정에 총단이 담당 호차 지정 | 담당 호차의 상행·하행 탑승 확인 |

순장·순원은 직접 신청하지 않으며 임역원이 대리 입력합니다.
명단의 역할 표시와 로그인 계정의 접근 권한은 별개입니다.

## 주요 기능

| 업무 | 할 수 있는 일 |
|---|---|
| 행사 운영 | 행사 선택, 행사별 자료 조회, 운영 단계·활성 행사 관리 |
| 명단 관리 | 이름·학번 검색, 캠퍼스 필터, 추가·수정·제외, CSV 가져오기·미리보기·내보내기 |
| 참석·이동 | 참여 예정 기간과 시각 입력, 방향별 버스 편·이동수단 선택, 부분 참석 화면에서 바로 수정 |
| 집회장 현장 기록 | **집회장 도착·집회장 떠남** 체크, 반복 방문 확인, 사유를 남기는 기록 정정 |
| 운행·배차 | 상행·하행 운행편과 차량 편성, 방향별 자동 배차, 수동 배정, 좌석·정원 조회 |
| 리더·간사 차량 | 캠퍼스·역할·미지정 필터와 검색, 방향별 차량순장·고정 탑승자 지정, 총단의 간사 차량 배정·변경·해제 |
| 버스 출석 | 상행 탑승·하행 귀가 체크, 호차별 명단 확인, 다른 기기의 변경 반영 |
| 수송·수강신청 | 선택 수송 요청·수강신청 입력, 날짜별 시간표, 같은 날짜·시각의 여러 사람 표시 |
| 차량비 정산 | 개인 납부·캠퍼스 송금·총단 확인 비교, 누적 장부, 면제자·차액 확인, 변경 시각과 개인 활동 기록 대조 |
| 변경 확인 | 변경 내역·활동 기록·오류 점검, 동시에 수정했을 때 충돌 안내와 복구 |

자동 배차는 상행과 하행을 각각 계산합니다. 운행편과 차량 정원을 확인하고,
차량순장·고정 탑승자와 기존 배정 규칙을 반영합니다.
간사 차량은 총단이 방향과 차량을 고른 뒤 사람을 검색해 고정 탑승자로 지정할 수 있습니다.

## 기본 사용 흐름

1. **행사 준비**: 총단이 행사·운행편·차량을 준비하고 담당자의 접근 권한을 지정합니다.
2. **신청 입력**: 임역원이 명단과 참석 일정·이동수단을 입력합니다. CSV로 여러 사람을 가져올 수도 있습니다.
3. **배차 확인**: 총단이 자동 배차·수동 배정을 진행하고 차량순장과 고정 탑승자를 지정합니다. 임역원은 배정 호차를 확인합니다.
4. **일정 조율**: 필요한 수송 요청·수강신청을 입력하고 날짜별 시간표에서 사람·시각·장소를 함께 확인합니다.
5. **현장 확인**: 차량순장이 버스 탑승을 확인하고, 담당자가 집회장 도착·떠남을 기록합니다.
6. **정산 대조**: 개인 납부, 캠퍼스 송금, 총단 확인 기록을 비교하고 차액과 변경 이력을 확인합니다.

## 참석 정보는 이렇게 구분합니다

- **참여 예정 일정**: 신청할 때 확정한 시작·종료 날짜와 시각입니다.
- **집회장 도착·집회장 떠남**: 현장에서 체크한 실제 방문 기록입니다.
- **상행 탑승·하행 귀가**: 차량 탑승 체크입니다. 집회장 방문 기록과 따로 관리합니다.

부분 참석·편도 이용·우리 버스 외 이동이 포함된 신청은 예정 시작·종료 일시가 모두 확정되어야 합니다.
버스를 이용하지 않는 방향도 이동수단을 선택해야 합니다. **수송 요청과 수강신청은 선택 사항**입니다.
날짜·시각은 한국 시간(KST, UTC+9)을 기준으로 입력하고 표시합니다.

과거 자료의 비어 있는 시각은 자동으로 채우지 않습니다.
새 등록이나 참석·이동 정보를 변경할 때 확정 일정을 확인하며,
기존 자료의 이름·납부·출석만 수정할 때는 새 일정 입력을 강제하지 않습니다.

## 화면 구성

| 사용자 | 업무 메뉴 |
|---|---|
| 총단·조회 운영자 | 현황, 명단·참여, 차량·이동, 정산, 운영 관리 |
| 임역원 | 명단·참여, 차량·이동, 정산 |
| 차량순장 | 담당 호차의 상행·하행 출석 확인 |

권한에 맞는 메뉴와 작업을 제공합니다. 총단·조회 운영자는 선택한 행사의 자료를 보고,
임역원은 본인 캠퍼스의 자료를 관리합니다.

명단·정산처럼 비교가 필요한 정보는 표로 유지하고,
일정은 날짜별 시간표, 호차·좌석·운영 상태는 업무에 맞는 요약으로 보여줍니다.
화면 폭에 따라 메뉴와 내용 배치를 조정하며, 같은 화면에서 여러 사람을 이어서 수정할 수 있습니다.

## v3.0.0에서 달라진 점

- 역할별 업무 메뉴와 검색, 공통 흑백 디자인, 정보량에 맞는 화면 배치.
- 확정 참석 예정 일시·방향별 이동수단 입력, 부분 참석 화면에서 바로 수정.
- 집회장 실제 방문·정정 기록과 버스 출석 구분.
- 수강신청·수송 요청의 날짜별 시간표와 겹치는 신청 표시.
- 정산 관련 변경 시각과 개인 활동 기록 연결.
- 리더 목록 정렬·검색·필터와 간사 차량 고정 탑승자 직접 배정.
