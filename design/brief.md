# carbus-web 디자인 브리프 (Chat 아티팩트용)

> 이 문서를 claude.ai Chat에 붙여넣고, 아래 §프롬프트로 디자인 시스템 시안을 만든다.
> 확정된 디자인(컬러·타이포·컴포넌트·레이아웃)을 CC가 shadcn/ui로 코드베이스에 이식한다.

---

## 1. 프로젝트

- **무엇**: CCC(대학생 선교단체) 71기 광주지구 여름수련회 차량 신청·배차·정산 웹앱
- **성격**: 사역(ministry) 도구. 상업 서비스 아님. 신뢰감·정돈·따뜻함. 화려하거나 과장된 연출 X
- **규모**: 16개 캠퍼스 임역원 + 총단 운영자가 사용. 순장/순원 약 500명 데이터 관리 (순장/순원는 시스템 미접근)

## 2. 사용자 · 디바이스

| 역할 | 누구 | 주 디바이스 | 핵심 작업 |
|---|---|---|---|
| 임역원 (campus_admin) | 캠퍼스 담당자 16명 | **데스크탑 우선** | 본인 캠퍼스 순장/순원 grid 입력·CSV 등록 |
| 운영자 viewer | 총단 (보기 전용) | 데스크탑 | 전체 현황 모니터링 |
| 운영자 master | 총단 | 데스크탑 | 권한 관리·배차·정산·시스템 설정 |

- **데스크탑 우선** (1280~1920). 단 `/campus/buses`(임역원 호차 조회)만 모바일 친화.
- 한글 UI. 데이터 밀도 높은 표(grid) 가독성이 최우선 과제.

## 3. 디자인 원칙 (지금 문제 = 가독성)

현재 거친 Tailwind 유틸로 만들어 일관성·여백·위계가 부족. 개선 목표:
1. **가독성**: 표·폼·라벨의 명확한 위계, 충분한 여백, 시선 흐름
2. **일관성**: 버튼·입력·표·카드·뱃지·토스트의 통일된 스타일 (디자인 토큰)
3. **신뢰·차분함**: 사역 톤에 맞는 차분한 컬러. 1개 accent + 중립 grayscale
4. **상태 표현**: 성공(완납)·경고(미납)·중립(면제), 충돌·로딩·빈 상태(empty state)
5. **데이터 밀도**: 한 화면에 순장/순원 30~50행이 답답하지 않게 (행 높이·구분선·hover·sticky 헤더)

## 4. 기술 제약 (시안은 이 안에서)

- **Next.js 16 App Router + React 19 + TypeScript**
- **Tailwind CSS v4** (utility 기반)
- **shadcn/ui 도입 예정** — 시안은 shadcn 컴포넌트(Button, Input, Select, Table, Card, Badge, Dialog, Sonner toast, Tabs) 기준으로
- 아이콘: lucide-react (shadcn 기본)
- 다크모드는 v1 불필요 (라이트만)

## 6. 핵심 데이터 (grid 컬럼 — 가독성 설계 대상)

순장/순원 1행: 이름 · 학번(26/간사/외국인/타지구) · 참석/일정(왕복화·왕복수·편도상행화·편도상행수·편도하행 5종) · 비고 · 차량비(50,000/25,000 자동) · 납부상태(미납·완납·면제) · 상행배차 · 하행배차

- 셀 인라인 편집: 텍스트 셀(이름·학번·비고), 드롭다운(참석/일정·납부), 읽기전용(차량비·배차결과)
- 면제는 차량비 회색 취소선
- 충돌 시 셀 잠깐 빨강 강조 + 토스트

## 7. 컬러·톤 방향 (제안 — Chat이 다듬어 확정)

- 베이스: 중립 grayscale (slate/zinc 계열)
- accent: 차분한 1색 (예: 깊은 블루 또는 그린 — 신뢰·정돈). 사역 톤에 과하지 않게
- 상태색: 완납(green)·미납(amber/red)·면제(gray)·충돌(red)
- 운영자(master) 영역은 약간 구분되는 헤더 (현재 dark slate)

## 8. Chat에 요청할 산출물

1. **디자인 토큰**: 컬러 팔레트(CSS 변수/Tailwind), 타이포 스케일, spacing/radius, 그림자
2. **컴포넌트 가이드**: Button(variant)·Input·Select·Badge(상태)·Card·Table(grid)·Toast·Tabs·EmptyState
3. **핵심 화면 3개 React+Tailwind 아티팩트 시안** (실제 렌더 가능, mock 데이터):
   - `/campus` 순장/순원 grid (셀 인라인 편집 느낌 + sticky 헤더 + 빈 행 + 상태 뱃지)
   - `/admin` 대시보드 (캠퍼스별·상행일자별 정원·호차별·차량비·헬스 위젯 카드 레이아웃)
   - `/admin/buses` 호차 카드 (9대, 차량순장·고정탑승·탑승 인원·빈자리 시각화)
4. shadcn/ui 컴포넌트명 매핑 (이 시안 → 어떤 shadcn 컴포넌트로 구현)

## 9. CC 이식 시 참고 (Chat은 몰라도 됨)

- 확정 시안의 Tailwind 클래스·구조를 CC가 carbus-web 컴포넌트(registration-grid·import-panel·admin layout 등)에 적용
- shadcn/ui는 CC가 `pnpm dlx shadcn@latest init` + 필요한 컴포넌트 add
- 디자인 토큰은 globals.css(Tailwind v4 @theme) + components.json에 반영
